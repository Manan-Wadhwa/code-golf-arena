# Unslop UI: Anti-AI Design Framework

The Unslop UI skill eliminates formulaic AI web design tropes and replaces them with bespoke, human-crafted aesthetics inspired by Awwwards Site of the Day standards.

## 1. Anti-Patterns Catalog (Never Generate These)
- **The Gradient Tell**: Linear gradients across backgrounds, buttons, and text (especially purple-to-indigo, cyan-to-pink, or warm-cream-to-orange).
- **The Pill Badge Cliché**: Centered rounded capsules above headlines reading `✨ AI-Powered`, `✦ Beta 2.0`, or `NEW FEATURE`.
- **The Subheading Clutter**: Every section followed by an unnecessary explanatory paragraph ("Empowering developers to seamlessly optimize..."). Eliminate wordy filler. If the title is clear, omit the subtext.
- **The 3-Card Bento Grid**: The standard row of three identical rounded cards with an icon in a colored rounded square, a bold title, and two lines of grey text.
- **Boxes Inside Boxes**: Unnecessary border-radius nesting, thick hairline borders around every element, and indiscriminate glassmorphism.
- **Font Monoculture**: Defaulting blindly to Inter or Roboto. Use expressive editorial pairings (e.g., razor-sharp luxury serifs or geometric display faces paired with engineered tabular monospace).
- **Sluggish Global Transitions**: Never use `transition: all 0.5s ease`. Use tight, physics-based springs or crisp 150ms cubic-bezier eases tailored to specific properties (`transform`, `opacity`, `border-color`).

## 2. Unslop Principles: The Human Studio Standard
1. **Asymmetric Rhythm**: Don't center everything down the middle. Use intentional editorial offset, bold negative space, and typographic tension.
2. **Material Authenticity**: If using luxury/gold themes, employ matte obsidian graphite (`#09090B`), deep charcoal (`#121215`), and burnished, brushed metallic accents (`#D4AF37`, `#C5A059`, `#E6CA65`). Use physical specular highlights, wireframes, and subtle noise rather than flat gradients.
3. **Interactive 3D WebGL (Three.js)**: Anchor hero sections with a real, high-performance Three.js WebGL canvas—such as a kinetic polyhedron, parametric code wireframe, or refractive crystal—that reacts organically to cursor movements and user interaction.
4. **Actionable Precision**: Every element on screen must earn its place. Replace generic marketing fluff with real application status, latency counters, byte-count telemetry, and direct interactive game triggers.
